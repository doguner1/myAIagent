# Career Profile & Technical Competency Synthesizer (AI Job Search Architecture)

## Overview
Based on `MadsLorentzen/ai-job-search`, this skill provides automated evaluation of technical project portfolios, mapping real development artifacts (commits, architectures, repos) to technical roles, and identifying competency gaps.

## Methodology
1. **Repository Evidence Mining:**
   - Extract real technical capabilities from codebase architectures, commit histories, and deployment pipelines rather than generic resumes.
2. **Gap & Opportunity Analysis:**
   - Map project competencies against frontier engineering requirements (AI agents, systems engineering, reverse engineering, mobile security).
3. **Structured Portfolio Alignment:**
   - Generate grounded, factual summaries of engineering accomplishments with verifiable technical citations.
